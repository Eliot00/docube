* @docube/org

Transform your Org content into type-safe data collections.

** Installation

*** npm

#+begin_src shell
npm i @docube/org -D
#+end_src

*** pnpm

#+begin_src shell
pnpm add @docube/org -D
#+end_src

*** yarn

#+begin_src shell
yarn add @docube/org --dev
#+end_src

*** bun

#+begin_src shell
bun add @docube/org --dev
#+end_src

** Usage

1. Create a ~generate.ts~ file at the root of your project:

  #+begin_src typescript
  import { transform } from "@docube/org";

  await transform({
    name: "Post",
    directory: "posts",
    include: "**/*.org",
    fields: (s) => ({
      title: s.String,
      summary: s.String,
      tags: s.Array(s.String),
      publishedAt: s.String,
    }),
    rehypePlugins: [/* rehypePrettyCode, rehypeSlug, ... */],
    contentTransform: (converted) => {
      // Org keywords come out snake_case with tags as a single string —
      // normalize them into the shape declared in `fields`.
      const { published_at, tags, ...rest } = converted;
      return {
        ...rest,
        publishedAt: published_at,
        tags: String(tags).trim().split(" "),
      };
    },
  });
  #+end_src

2. Start writing content in ~posts~:

  #+begin_src orgmode
  #+TITLE: Hello World
  #+SUMMARY: This is my first post
  #+TAGS: news demo
  #+PUBLISHED_AT: 2026-01-01

  * Hello World

  This is my first post.
  #+end_src

3. Run ~generate.ts~, recommend use ~esrun~ or ~bun~:

  #+begin_src shell
  bun generate.ts
  #+end_src

4. Update your ~tsconfig.json~:

  #+begin_src json
  "paths": {
    "@docube/generated": ["./.docube/generated"]
  }
  #+end_src

5. Use your content in your app:

  #+begin_src tsx
  import { allPosts } from "@docube/generated";

  export function Posts() {
    return (
      <ul>
        {allPosts.map((post) => (
          <li key={post._meta.slug}>
            <a href={`/posts/${post._meta.slug}`}>
              <h3>{post.title}</h3>
              <p>{post.summary}</p>
            </a>
          </li>
        ))}
      </ul>
    );
  }
  #+end_src

  #+begin_src tsx
  import { allPosts } from "@docube/generated";

  export function Post({ slug }) {
    const post = allPosts.find((p) => p._meta.slug === slug);

    return (
      <article dangerouslySetInnerHTML={{ __html: post.body }} />
    );
  }
  #+end_src

** Notes

- ~contentTransform~ runs after the org file is converted (frontmatter + ~_meta~ + ~body~)
  and before schema validation. Use it to rename keywords, coerce types, or drop
  fields that are not part of your ~fields~ schema.
- ~transform~ returns a ~Promise~ — validation failures and IO errors reject it,
  so running ~bun generate.ts~ fails loudly instead of exiting silently.
